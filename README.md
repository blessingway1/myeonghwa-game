# 명화 사건파일

명화 속 단서를 눌러 찾고, 그 뒤의 이야기와 보는 법을 읽고, 마지막 추리로 사건을 닫는 게임.

- 게임: https://blessingway1.github.io/myeonghwa-game/
- 바로가기: 주소 끝에 `#scene=skull`·`#scene=shadow`·`#scene=note`(한 장면 찾기), `#case=<사건 id>`(사건)

## 그림
수록 작품 10점은 모두 퍼블릭 도메인이며 위키미디어 공용(Wikimedia Commons)에서 받았다.
아르놀피니 부부의 초상(얀 반 에이크), 대사들(한스 홀바인 2세), 시녀들(디에고 벨라스케스), 야경(렘브란트),
네덜란드 속담(피터르 브뤼헐), 쾌락의 정원(히에로니무스 보스), 절규(에드바르 뭉크), 폴리베르제르의 술집(에두아르 마네),
열린 창가에서 편지를 읽는 여인(요하네스 페르메이르), 마담 X(존 싱어 사전트).
`img/scream_note.jpg`는 〈절규〉 하늘 부분을 대비를 높여 확대한 사진이다.

## 방문 집계
GoatCounter로 방문 수와 게임 단계(사건 시작·단서 1~5·해결)를 센다. 쿠키를 쓰지 않고 개인 정보를 모으지 않는다.
